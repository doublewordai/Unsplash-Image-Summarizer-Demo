# Unsplash Image Summarizer Demo

This demo project shows how to do Image Processing with Doubleword’s inference API, by summarizing Unsplash images. Each image’s metadata is converted into a social media–style summary.

As of January 27th 2026, the cost of summarising 1000 720p images with the Qwen-30B model on [Doubleword's inference platform](https://app.doubleword.ai) is $0.05.

---

## Features

* Processes **Unsplash Lite dataset** (first 1000 images for demo purposes)
* Sends image, description and photographer to an LLM for social media–style summaries
* Outputs a CSV with columns: `photo_image_url`, `photo_description`, `photographer_username`, `summary`

---

## Requirements

* Python 3.10+
* [Autobatcher](https://github.com/doublewordai/autobatcher)
* [pandas](https://pandas.pydata.org/)
* [python-dotenv](https://pypi.org/project/python-dotenv/)
* [asyncio](https://docs.python.org/3/library/asyncio.html) (standard library)

---

## Setup Instructions

### 1. Clone the repo

```bash
git clone <your-repo-url>
cd <your-repo-folder>
```

---

### 2. Create a Python virtual environment and install dependencies

```bash
python -m venv venv
source venv/bin/activate   # macOS/Linux
# .\venv\Scripts\activate # Windows

pip install --upgrade pip
pip install -r requirements.txt
```

---

### 3. Acquire the Unsplash Lite Dataset

1. Go to the [Unsplash Datasets GitHub](https://github.com/unsplash/datasets)
2. Download the **Lite dataset** (`unsplash-research-dataset-lite-latest.zip`)
3. Extract the folder into your project directory so you have:

```
Unsplash-Image-Summarizer-Demo/
├── unsplash-research-dataset-lite-latest/
│   ├── photos.csv000
│   ├── keywords.tsv
│   └── ...
├── main.py
├── requirements.txt
├── README.md
└── ...
```

> The script expects `photos.csv000` at `unsplash-research-dataset-lite-latest/photos.csv000`.

---

### 4. Set up `.env` file

Create a `.env` file in the project root:

```
DW_API_KEY=your_api_key_here
```

> Replace `your_api_key_here` with your actual API key from Doubleword AI (or another OpenAI compatible batch inference provider).

---

### 5. Run the summarization script

```bash
source venv/source venv/bin/activate
python main.py
```

* The script will:

  1. Load the first **1000 images** from the dataset
  2. Build prompts and send requests to the LLM via **Autobatcher**
  3. Save the output CSV as `unsplash_summaries_1000.csv`

---

### 6. Output

The output CSV will have the following columns:

| photo_image_url      | photo_description         | photographer_username      | summary                                 |
|----------------------|--------------------------|---------------------------|-----------------------------------------|
| Unsplash image URL   | Unsplash image description| Unsplash photographer username | Social media–style summary generated by LLM |

---

## Notes / Tips

* You can adjust the number of images processed by changing `NUM_IMAGES` in `main.py`.
* Batch size and batch window in Autobatcher can be tuned for faster performance.
* This demo **does not scrape**; it only uses freely available Unsplash images and metadata.
* You can edit the prompt for the LLM to have a more professional/casual tone for your use case.
